# Ker Nethalas

Anvil and Loom's unofficial Windows companion for Ker Nethalas. This is a development preview.

## Download and install

[Download the Windows installer (v0.1.0, x64)](https://github.com/AnvilAndLoom/Ker-Nethalas-Releases/releases/download/v0.1.0/Ker-Nethalas-0.1.0-windows-x64-setup.exe)

1. Run **Ker-Nethalas-0.1.0-windows-x64-setup.exe**.
2. Choose the application folder and a separate folder for expedition saves. The default is **Documents\Ker_Nethalas\Expeditions**.
3. Open **Ker Nethalas** from its shortcut.

No Node.js or npm is needed. The installer is currently unsigned.

## Updates and saves

The **App updates** panel on the opening Expeditions screen checks for new versions. Download and restart are your choices. Updates preserve the selected expedition folder; uninstall leaves saves intact.

The app includes an expedition library, character sheets, exploration, combat, inventory, camp, journal, physical dice and a short menu tour. Rulebook PDFs are not included.

[Release notes and downloads](https://github.com/AnvilAndLoom/Ker-Nethalas-Releases/releases)

This repository distributes installers and update metadata. Application source is maintained privately. The first release passed automated tests, Windows packaging and an isolated packaged startup check. A clean installation and an installed upgrade to a later version are still pending validation.
